# 短视频审核 — 勾选 / 采集 / 删除工具集

目标页面：`https://tools.vobile.cn/quality/qualityTest*`（Vobile 短视频质量测试审核页，Ant Design 表格，单页约 100 条）

> ⚠️ 同一页面**同一时间只启用一个脚本**，避免重复勾选或误操作。下面 5 个脚本按场景选择其一。

## 脚本清单

| 脚本 | 版本 | 场景 | 本地后端 |
|------|:---:|------|:---:|
| [短剧审核自动勾选-增强版](短剧审核自动勾选-增强版.user.js) | 2.0.0 | 自动识别命中条目并勾选 + **自动批处理**（扫描→批量正确→全选→批量错误→下一批，20 秒无新数据自动停止） | ✅ 必需 |
| [短剧审核自动勾选-基础版](短剧审核自动勾选-基础版.user.js) | 2.0.0 | 自动识别命中条目并勾选，翻页自动重置；**无自动批处理**，勾选后由人工提交 | ✅ 必需 |

## 各脚本详细说明

### 1. 短剧审核自动勾选-增强版（推荐）

在基础版之上叠加了三项能力，适合无人值守的批量处理：

- **批量人脸检测**：通过 `GM_xmlhttpRequest` 直接下载图片 URL → base64 → 批量调用 `/detect_batch`（每批 3 张），下载失败自动回退「预览大图截屏」单条检测
- **低分跳过**：得分 < `scoreThreshold`(默认 80) 的行直接跳过，不检测不勾选
- **自动批处理**：勾选命中 → 「批量正确」提交 → 全选剩余 → 「批量错误」提交 → 等待系统刷新下一批（20s 内无新数据判定处理完成）→ 循环

关键配置：`backendUrl`、`rateLimit`(5条/秒)、`batchSize`(3)、`scoreThreshold`(80)、`nextBatchWaitMax`(20000ms)、`batchActionWait`(2500ms)。面板含「自动批处理」开关。

### 2. 短剧审核自动勾选-基础版

- 逐行检测：图片（打开 AntD 预览大图，按屏幕坐标截图调 `/detect`）+ 文本（`/detect_text_name` 人名识别）
- 命中自动勾选；`MutationObserver` 监听表格翻页自动重置重扫；滚动 300ms 防抖
- 勾选后由人工点击「批量正确 / 批量错误」提交

### 3. 低分key_id采集

- 规则：**得分 ≤ 阈值(默认 80)** **或** **第 7 列名称含关键词**（默认内置 12 个演员名关键词，可面板修改）→ 采集第 15 列 key_id
- 翻页采用「页码高亮 + 首行 key_id 变化」双保险判定，等待数据渲染完整后再采集，修复翻页过快导致的数据不全
- 完成或手动点击「复制全部 key_id」将结果（逗号分隔）写入剪贴板

### 4. 无人脸ID提取

- 规则：**无人脸** **或** 名称含关键词 **或** 分数 < 阈值(默认 80) → 提取 key_id
- 每批 3 张并发下载图片 → `/detect_batch` 人脸检测；支持从当前页开始（面板记录起始页码）
- 结果自动复制到剪贴板，日志面板实时显示进度

### 5. 自动全选批量删除

- 每轮：等待表格稳定 → 表头全选 → 点「批量删除」→ 自动确认弹窗 → 等待 10s（系统处理删除）→ 下一轮
- 表格无数据时判定全部删除完成并停止

## 页面列结构依赖（qualityTest 页）

| 列 | 内容 | 用到的脚本 |
|----|------|-----------|
| 第 1 列 | 复选框 / 全选框 | 勾选、删除 |
| 第 7 列 | 文本（样本名） | 关键词筛选（采集/提取） |
| 第 8 列 | 得分 | 低分筛选（勾选跳过/采集/提取） |
| 第 15 列 | key_id | 采集、提取 |
| 图片列 | `.ant-image-img` 缩略图 | 人脸检测 |

## 本地后端依赖说明

标记「✅ 必需」的脚本需要本地 Python 服务监听 `127.0.0.1:5002`，依赖接口：

| 接口 | 用途 |
|------|------|
| `POST /detect` | 屏幕坐标截屏 + Haar 人脸检测 |
| `POST /detect_batch` | base64 图片批量人脸检测 |
| `POST /detect_text_name` | 百度 LAC 人名识别 |
| `POST /health` | 健康检查（脚本启动时自动检测） |

后端接口契约详见 [docs/项目需求说明.md](../docs/项目需求说明.md)。使用前先启动后端，浏览器窗口保持非最小化且不被遮挡，浏览器缩放建议 100%。

## 使用步骤

1. 启动本地后端（需要后端的脚本）
2. Tampermonkey 安装对应脚本
3. 打开 `qualityTest*` 页面，等待右下角面板出现
4. 配置阈值/关键词 → 点击「开始」→ 等待结果（采集/提取完成后自动复制 key_id 到剪贴板）
