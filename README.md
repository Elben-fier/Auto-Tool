# Auto-Tool — Vobile 内容审核自动化工具集

针对 **Vobile 内容审核平台**（`tools.vobile.cn`）日常审核作业开发的一套 Tampermonkey 油猴脚本 + 本地 Python 检测后端，覆盖「**短剧审核批量判错**」与「**短视频审核勾选 / 采集 / 删除**」两大场景，把重复性人工操作变成规则化的自动批处理。

> 所有图片与文本检测**均在本机完成**（回环地址 `127.0.0.1:5002`），不上传任何外部服务器。

---

## ✨ 核心能力

| 能力 | 说明 |
|---|---|
| **智能判错（短剧审核 9.1）** | 判定链：关键词双列比对（命中词缺任一个在第4列 → 全错）→ 低分下限（硬规则）→ 其余一律**展开核对**（低分<80 多于正确数据 → 全错；否则 得分≥93 ≥4 条 或 777/601 达标 → 通过），据此决定「全剧审核（模式1）」还是「全选 + 批量错误 + 查 询刷新（模式2）」 |
| **状态码闸门** | 批量错误后**必须等全部子样本状态码变 594**（且页面转圈结束）才点全剧审核，杜绝"系统还在处理脚本就点下一步" |
| **严格等待加载** | 所有点击前 / 展开后 / 提交后都等 antd 转圈消失；转圈期间不做完成判定 |
| **容错与自愈** | 等待 30s / 60s 各自动重试点击一次；仍无响应则**永久跳过该合集并继续下一行**；问题合集自动收起 |
| **人像检测（本地）** | YOLOv8n(person) + YuNet(人脸兜底)：人脸 / 背影 / 侧脸 / 全身都算"有人"；手机、屏幕（电视/显示器/笔记本）单独识别 |
| **图片相似度（本地）** | SSIM + dHash(8/16) + HSV 直方图 + 宽高比 加权比对，用于"第5列 vs 第6列"一致性校验 |
| **一键勾选（短视频）** | 一页一轮：错误行勾选→批量错误、其余勾正确→批量正确，逐页自动循环 |
| **可观测** | 面板实时状态与进度、逐行判错原因、TSV 明细/跳过清单一键复制到剪贴板 |

## 🚀 快速开始

```bash
# 1) 后端：装依赖 + 放模型（模型获取见 backend/README.md）+ 启动
cd backend
pip install -r requirements.txt
python server.py          # 或双击 run.bat

# 2) 浏览器：Tampermonkey 导入对应 .user.js（同页面只启用一个脚本）
# 3) 打开审核页面，右下角出现控制面板，点「开始」
```

- 详细步骤与调参：**[docs/部署与使用指南.md](docs/部署与使用指南.md)**
- 接口与算法：**[docs/后端接口与算法说明.md](docs/后端接口与算法说明.md)**
- 版本演进与判定规则：**[docs/版本演进记录.md](docs/版本演进记录.md)**
- 短剧审核 9.1 判定机制拆解：**[docs/短剧审核9.1判定机制详解.md](docs/短剧审核9.1判定机制详解.md)**（判定优先级、展开核对判据、等待/重试、日志字段、已知疑点）
- 判定日志（短剧审核脚本自动上报）：启动后端后打开 **<http://127.0.0.1:5002/judge_log/view>**（可筛选、导出 CSV；存储于 `backend/logs/judge_log.jsonl`）

## ⚠️ 注意事项

1. **不可逆操作**：脚本会真实执行「批量错误 / 批量正确 / 全剧审核 / 批量删除」，请先在少量数据上验证规则与阈值；
2. **一页一脚本**：同一页面不要同时启用多个脚本；
3. **窗口约束**：依赖屏幕坐标截屏的功能（`/detect`）要求浏览器窗口不最小化、目标区域不被遮挡，建议缩放 100%；
4. **数据安全**：图片与文本检测全部在本机完成，无数据外发；
5. **识别率**：人像/人脸模型对极小目标、严重遮挡、强模糊仍有漏检可能，可用面板阈值与 `detector.py` 常量微调。
