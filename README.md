# Auto-Tool — Vobile 内容审核自动化油猴脚本集

针对 **Vobile 内容审核平台**（`tools.vobile.cn`）日常审核作业开发的一套 Tampermonkey 油猴脚本，覆盖「短剧审核批量判错」与「短视频审核勾选 / 采集 / 删除」两大场景，把重复性人工操作自动化，显著提升审核效率。

> 所有数据均在本机处理：图片检测、文本识别通过本地回环接口（`127.0.0.1:5002`）完成，不上传至任何外部服务器。

## 🚀 快速开始

### 1. 安装 Tampermonkey

1. 在 Edge / Chrome 应用商店安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 打开扩展管理面板 →「实用工具」→「导入」，选择本仓库中的 `.user.js` 文件；或直接在 GitHub 页面点击 `.user.js` 文件后按提示安装。
3. 建议一次只启用一个**同一页面**的脚本，避免冲突：
   - `dramaReview*` 页面：启用 `短剧审核4.5.user.js`（当前推荐版）
   - `qualityTest*` 页面：按需启用「自动勾选 / 采集 / 删除」之一

### 2. 启动本地 Python 后端（仅勾选 / 提取类脚本需要）

- 运行环境：Windows + Python 3.10
- 后端在 `127.0.0.1:5002` 提供以下接口（接口契约详见需求文档）：

| 接口 | 说明 |
|------|------|
| `POST /detect` | 按屏幕绝对坐标截取浏览器区域，Haar 级联人脸检测 → `{"hasFace": bool}` |
| `POST /detect_batch` | 批量 base64 图片人脸检测 → `{"results": [bool, ...]}` |
| `POST /detect_text_name` | 百度 LAC 中文人名实体识别 → `{"hasPerson": bool}` |
| `GET/POST /health` | 健康检查 |
| `POST /debug_screenshot` | 调试：按坐标截图保存 |

- 浏览器窗口**不可最小化、不可被遮挡**；建议浏览器缩放 100% 以保证坐标映射精度。

### 3. 开始使用

- 打开对应审核页面，等待表格加载完成，脚本右下角出现可拖拽控制面板。
- 点击「开始」/「开始扫描」即可；面板可实时查看命中数、进度与日志。

## ⚠️ 注意事项

1. **窗口约束**：依赖屏幕截图的脚本，浏览器窗口不能最小化，待检测区域不能被其他窗口遮挡。
2. **识别率**：Haar 正脸检测器对侧脸/遮挡/模糊图片可能漏检；LAC 对真实人名准确、对虚构角色名可能漏判；可通过检测器 `scaleFactor` / `minNeighbors` 参数微调。
3. **脚本冲突**：同一页面请勿同时启用两个脚本，避免重复勾选/误操作。
4. **业务风险**：脚本会真实执行「批量错误」「全剧审核」「批量删除」等**不可逆操作**，请先在测试数据上验证，并对阈值/关键词做充分配置。
5. **需求现状**：短剧审核自动勾选工具当前按需求暂缓人脸/人名处理（见 [docs/项目需求说明.md](docs/项目需求说明.md) 末尾备注）。
