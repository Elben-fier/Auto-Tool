# 部署与使用指南

从零开始把整套工具跑起来：环境准备 → 启动后端 → 安装脚本 → 使用与调参 → 排错。

---

## 一、环境准备

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 |
| 浏览器 | Microsoft Edge（Chrome 同样可用） |
| 浏览器扩展 | [Tampermonkey](https://www.tampermonkey.net/) |
| Python | 3.10（仅"需要检测能力"的脚本需要） |
| 网络 | 仅首次准备模型时需要；日常运行**全程本地**，不联网 |

> 建议浏览器缩放保持 **100%**（少数脚本会用屏幕坐标截屏，缩放会影响精度）。

## 二、启动本地后端

1. 准备模型文件（**必需**，仓库不包含）：

   | 文件 | 放到 | 获取 |
   |---|---|---|
   | `face_detection_yunet_2023mar.onnx` | `backend/` | 见 [backend/README.md](../backend/README.md) |
   | `yolov8n.onnx` | `backend/` | 同上（用 ultralytics 从 `yolov8n.pt` 导出） |

2. 安装依赖并启动：

   ```bash
   cd backend
   pip install -r requirements.txt
   python server.py
   ```

   或直接双击 `backend/run.bat`。

3. 看到 `[detector] YOLOv8n.onnx 加载成功（YOLO 模式）` 与 `Running on http://127.0.0.1:5002` 即成功。
   浏览器打开 <http://127.0.0.1:5002/health> 验证：`{"status":"ok"}`。

> 后端窗口**不要关闭**（可最小化）。关掉后所有需要检测的脚本都会报"请求失败"。
> 若提示端口被占用，先结束旧的 `python server.py` 进程再启动。

## 三、安装脚本

1. Tampermonkey → 「实用工具」→「导入」，选择对应的 `.user.js`；
2. 也可以新建脚本后把内容整段粘贴保存；
3. **同一页面同一时间只启用一个脚本**，避免两个脚本抢操作。

| 页面 | 推荐脚本 | 是否需要后端 |
|---|---|---|
| `quality/dramaReview*`（短剧审核） | `短剧审核9.0.user.js` | 否 |
| `quality/qualityTest*`（短视频审核） | `短视频审核-一页勾选版.user.js` | ✅ 需要 |
| `quality/qualityTest*`（提取+删错） | `短剧审核-标签版v2.2-YOLO.user.js` | ✅ 需要 |
| `quality/dramaReview*`（平台筛选） | `平台筛选自动全选.user.js` | 否 |

## 四、各脚本使用

### 1. 短剧审核 9.0（`dramaReview*`）

1. 打开页面，右下角出现紫色「短剧审核助手 9.0」面板；
2. 可选调整：起始行号 / 匹配分阈值 / 慢处理集数，勾选框「严格等待加载完成」（默认开）；
3. 点「开始运行」→ 自动循环：展开 → 判定 → 直接全剧审核 或 全选+批量错误 → 全剧审核 → 下一行；
4. 面板实时显示当前步骤与 594 进度；「复制跳过清单」可导出被永久跳过的合集（含 id/名称/原因）。

### 2. 短视频审核-一页勾选版（`qualityTest*`）

1. 先启动后端；
2. 打开页面，出现蓝色「短视频勾选助手（完整版）」面板；
3. **先点「只扫当前页」**核对检测结果（面板日志 + F12 `console.table` 明细：有人/相似度/手机/屏幕/判定/原因）；
4. 想看点选效果但不提交：勾上 **「测试模式」** → 点「开始处理」（会真实勾选错误行，不点按钮）；
5. 正式跑：不勾测试模式 → 点「开始处理」→ 确认弹窗点确定 → 自动逐页处理；
6. 面板可现场调：低分判错阈值、相似度阈值、手机/屏幕阈值、人物阈值、每批张数；「复制明细(TSV)」「复制判错原因」便于分析。

### 3. 短剧审核-标签版 v2.2（`qualityTest*`）

单浮窗两标签：
- **人脸识别提取**：点「开始提取」遍历所有页，提取"无人脸/名称含关键词/低分"的 key_id，完成后自动复制到剪贴板；
- **批量判错删除**：切到该标签点「开始删除」，全选 → 批量错误 → 确认 → 循环直到清空。

### 4. 平台筛选自动全选（`dramaReview*`）

打开页面自动执行一次：重置平台多选框 → 展开下拉 → 滚动虚拟列表逐个点选全部平台；失败可在控制台执行 `window.__selectAllWebsites()` 重试。

## 五、调参与常见问题

### 检测结果不准怎么调

| 现象 | 调法 |
|---|---|
| 正确数据被判错（原因多为"相似度低"） | 降低**相似度阈值**（0.40 → 0.35），或关闭相似度规则 |
| 正确数据被判错（原因多为"检出手机/屏幕"） | 提高**手机/屏幕阈值**（0.55 → 0.65），或取消勾选「手机/屏幕 也判错」 |
| 剧照人物被漏判为"无人" | 降低**人物阈值**（0.35 → 0.25） |
| 低分数据被漏判 | 提高**低分判错**阈值（74 → 80） |

> 后端层面的阈值（`PERSON_CONF` / `OBJECT_CONF` / 相似度权重）在 `backend/detector.py` 顶部，改完**重启后端**生效。

### 常见报错

| 现象 | 原因 / 处理 |
|---|---|
| 面板日志刷"请求失败/超时" | 后端未启动或端口被占；确认 `http://127.0.0.1:5002/health` 可访问 |
| 大量"缺图/检测失败" | 脚本已做图片预热（滚动触发懒加载），若仍多，检查网络或把 `onDownloadFail` 改为 `skip` |
| 页面一直转圈导致脚本不动作 | 严格等待设计的预期行为；若某组件转圈卡死，可在面板临时关闭「严格等待加载完成」 |
| 剪贴板复制无效 | Tampermonkey 需授予剪贴板写入权限（脚本头部已声明 `GM_setClipboard`） |
| 提示"第2列合集id读取为空" | 页面结构可能改版，检查 `SELECTORS.parentIdCell` |

### ⚠️ 安全与合规

- 脚本会真实执行 **批量错误 / 批量正确 / 全剧审核 / 批量删除** 等**不可逆操作**，请先在少量数据上验证规则与阈值；
- 所有图片、文本检测**均在本机完成**，不上传任何外部服务器；
- 使用前请确认符合所在单位对自动化操作与数据安全的规定。
