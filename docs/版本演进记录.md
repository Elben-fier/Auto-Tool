### 9.0 判定链（当前实现）

```
⓪ 终极关键词命中（第3列）                    → 模式2（全选+批量错误+全剧审核）
① 普通关键词：第3列命中 & 第4列同词 → 疑似正确（继续）；第4列无该词 → 模式2
② 相似度闸门（短剧名 ≤4 字 且与第4列无相同词/字）：
     匹配分 < 90 → 模式2 ；匹配分 ≥ 90（或读不到）→ 进入 ④ 机制
③ 匹配分 > 95                                → 模式1（不展开，直接全剧审核）
④ 匹配分 ∈ [90, 95] → 展开：子样本得分 ≥90 的条数 ≥3 或 存在 601/777 → 模式1；否则模式2
⑤ 匹配分 < 90                                → 模式2（不展开）
⑥ 匹配分读不到 → 展开看 601/777 痕迹兜底
```

配套机制：严格等待加载（转圈闸门）、30s/60s 重试、永久跳过（换下一行）、问题合集收起、面板最小化与状态可视化。

### 一页勾选版判定链（当前实现）

```
① 得分 ≤ 74                       → 错误（低分，不送检测，省时间）
② 图片检测失败（下载/解码失败）      → 错误
③ 第5列 vs 第6列 相似度 < 0.40      → 错误
④ 检出手机 / 检出屏幕（置信度 ≥0.55）→ 错误
⑤ 无人（人物置信度 <0.35 且人脸未命中）→ 错误
以上都不命中                        → 正确
```

运行模式：

| 模式 | 行为 |
|---|---|
| 「只扫当前页」 | 只检测报告，不勾选不提交 |
| 测试模式（面板勾选） | 自动勾选错误行，但**不点**批量按钮（核对用） |
| 正式模式（默认） | 勾错误 → 批量错误 → 等错误行消失 → 勾正确 → 批量正确 → 等下一页刷新 |

### 历史演进要点（短视频系列）

| 阶段 | 做法 | 为什么改 |
|---|---|---|
| 基础版 / 增强版 | 人脸+人名识别 → 命中自动勾选 → 人工或自动提交 | 早期方案；文本人名识别准确率有限、预览截图检测慢 |
| 提取 ID（低分采集 / 无人脸提取） | 不勾选，只把可疑 key_id 提取到剪贴板，人工处理 | 早期模型（Haar）准确率不高，用"提取+人工确认"提高效率 |
| 标签版 v2.0 ~ v2.2 | 单浮窗双功能（提取 + 删错）合到一个脚本 | 两个浮窗太麻烦；标签切换更省地方 |
| **一页勾选版（当前）** | **YOLO 人像检测**可靠后回到勾选模式：自动判错→批量错误、其余→批量正确，逐页自动循环 | 模型换成 YOLOv8n + YuNet 后准确率达标，勾选模式效率最高 |
