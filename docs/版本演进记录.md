### 9.1 判定链（当前实现，9.1 文件 v9.4.4 / 9.2 文件 v9.2.1）

> ⚠️ **列号差异**：下表判据用到的"子样本状态码列 / 单条分列"，在 **9.2 起是第4列 / 第9列**（页面在第3列插入了 episode-index），在 **9.1 及以前是第3列 / 第8列**。判定逻辑两版完全一致。
> ⚠️ **判错完成口径**：**9.2.2 起 = "有效行里已无『未判定(0/空)』的行"且无转圈**（系统只会把 0/空码改成 594，**0 分行与 777·601 都不会变**）；9.2.1 = "有效行全部 = 594"（有效行含 777 时永远等不到）；9.2.0 及以前 = "全部子样本 = 594"（在该系统行为下同样永远等不到）。

> **核心**：除少数硬规则外，**一切都展开核对**；展开后的判据只看**子样本质量**（低分 / 高分 / 777·601 条数），其中"得分 = 0 或读不到"的行视为**还没刷新出来**、不计入统计。
> 相似度与匹配分**不参与决策**，只写进判定日志与判定理由。

```
①  关键词双列比对（v9.4.0：已取消终极关键词，全部走这条）
      第3列命中的**全部**关键词 → 只要有任一个在第4列没有 → 模式2（全错）
      全部命中词第4列都有 → 放行，继续往下判定
②  **母本最低线**：母本最高分（第5列 = 子样本单条分的最大值）< lowScoreFloor=90（面板可调）
      → 模式2（不看子样本的硬规则；**90 分是底线，777/601 够多也不救**）
③  其余一切情况（相似 / 不相似 / 匹配分高低 / 匹配分读不到）→ 展开核对：
      · 得分(第8列) = 0 或读不到的行走 → 还没刷新出来，不计入以下任何一项
      · 低分(<80) 条数 > 正确数据条数                     → 模式2（9.3.0 新增，优先）
      · 否则 得分 ≥ 93 的条数 ≥ 4                         → 模式1（点「全剧审核」）
        或 状态码 777 / 601 各自达标（有效行≤30条 ≥2；>30条 ≥4）→ 模式1
      · 都不满足                                           → 模式2（全选 + 批量错误 + 「查 询」）
      "正确数据" = 777/601 或 得分≥93（同一行只算一次）
```

模式1 动作：展开 → 「全剧审核」+ 确认 → 等转圈结束 → 等合集移走。
模式2 动作：展开 → 全选全部子样本 → 「批量错误」+ 确认 → 等全部 594 → 落库缓冲 → 点页面「查 询」刷新列表 → 等合集移走。

配套机制：严格等待加载（转圈闸门）、30s/60s 重试、永久跳过（换下一行）、问题合集收起、"匹配分读不到就跳过并重试"的保护（v9.2.1）、判定日志上报、慢处理（集数 > 300 时**所有等待闸门**统一放宽，v9.1.9 起全量生效）、**预演模式（只判定不点击，v9.3.0）**、面板最小化与状态可视化。

**扫描与结束（v9.2.0）**

```
每一轮：从面板「起始行号」往下扫描
   ├─ 「已审核」行  → 只作边界标记（说明下面都已审过），不当可审行
   ├─ id 读不到的异常行 → 跳过继续往下看（整段全读不到才判页面改版并停止）
   ├─ 已跳过(异常数据) / 本轮已处理过 → 跳过
   └─ 第一个可审行 → 处理它
扫不到可审行 → 点「查询」刷新列表确认（默认两次，每次等加载完成 + 1.5s 稳定后重扫）
   ├─ 刷新后出现可审行 → 继续审
   └─ 两次都没有   → 判定审核结束（口径：除「已审核」与「已跳过的异常数据」外，没有未审核行）
```


|---|---|
| 「只扫当前页」 | 只检测报告，不勾选不提交 |
| 测试模式（面板勾选） | 自动勾选错误行，但**不点**批量按钮（核对用） |
| 正式模式（默认） | 勾错误 → 批量错误 → 等错误行消失 → 勾正确 → 批量正确 → 等下一页刷新 |

### 历史演进要点（短视频系列）

| 阶段 | 做法 | 为什么改 |
|---|---|---|
| 基础版 / 增强版 | 人脸+人名识别 → 命中自动勾选 → 人工或自动提交 | 早期方案；文本人名识别准确率有限、预览截图检测慢 |
| 提取 ID（低分采集 / 无人脸提取） | 不勾选，只把可疑 key_id 提取到剪贴板，人工处理 | 早期模型（Haar）准确率不高，用"提取+人工确认"提高效率 |
| 标签版 v2.0 ~ v2.2 | 单浮窗双功能（提取 + 删错）合到一个脚本 | 两个浮窗太麻烦；标签切换更省地方 |
| **一页勾选版（当前）** | **YOLO 人像检测**可靠后回到勾选模式：自动判错→批量错误、其余→批量正确，逐页自动循环 | 模型换成 YOLOv8n + YuNet 后准确率达标，勾选模式效率最高 |
