# 修改方向与需求记录

> 本文件整理了短剧审核工具的需求变更记录，原始记录见 `修改方向-原始.txt`。

## 一、需求来源（原始记录）

```
1，增加全错筛选机制，要求如果每一条数据的短剧名携带某特定词语
  （比如"短剧""画""漫剧"我后续还会添加）就全选批错，
  并且短剧名字数小于等于3的也一律批错

2，<td class="ant-table-cell">画</td> 这里取样的，短剧名为"画"，
  直接全选判错判错，是数据的第三列样本
```

## 二、需求解析

- **触发场景**：母行（父级行）第 3 列展示的短剧名。
- **规则一（关键词命中）**：短剧名包含预设关键词（如「短剧」「画」「漫剧」等，后续可扩充）→ 该剧所有子样本**一键全选**并「批量错误」。
- **规则二（字数过短）**：短剧名字数 ≤ 3 → 同样全选判错。
- **取样参考**：`<td class="ant-table-cell">画</td>` —— 短剧名为单个「画」字，应直接全选判错。

## 三、实现落地（短剧审核4.5）

该需求在 **短剧审核4.5（v4.5.0）** 中实现，核心配置位于 `CONFIG`：

```js
// 全错筛选：短剧名包含以下任一关键词 → 全选判错
nameKeywords: ['短剧', '画', '漫剧', 'AI', '充电', '红果', '专属', '动画',
               '免费', '剪辑', '花絮', '拍摄', '经典', '剧', '真人', '免',
               '动漫', '动', '&', '定档', '首播', '漫', 'ai', '果'],
// 全错筛选：短剧名字数 ≤ 此值 → 全选判错
nameMinLength: 4
```

实现要点：

1. 新增选择器 `parentNameCell: 'td:nth-child(3)'` 定位母行短剧名列。
2. 新增 `checkParentName()` 判定函数：关键词命中 **或** 字数 ≤ `nameMinLength` → 返回"全错"。
3. 处理流程调整：`processOneDrama()` 中先执行全错判定，命中则直接 `selectAllChildRows()` 全选子样本，再走「批量错误 → 等待 2s → 全剧审核」流程；未命中则回退到原有阈值判错逻辑。

## 四、需求与实现的差异说明

| 需求原文 | 实现取值 | 说明 |
|----------|----------|------|
| 短剧名字数 **≤ 3** 一律批错 | `nameMinLength: 4`（即 ≤4 判错） | 实现比需求更严格，覆盖了 3 字及以内场景，同时纳入部分 4 字异常名 |
| 关键词示例：「短剧」「画」「漫剧」 | 关键词列表已扩充至 25 个 | 覆盖常见引流/搬运词，`'画'`、`'漫'`、`'短剧'`、`'剧'` 均单独命中，满足取样场景 |

> 如需收紧或放宽，直接修改脚本顶部 `CONFIG.nameKeywords` 与 `CONFIG.nameMinLength` 即可，无需改动其他逻辑。
