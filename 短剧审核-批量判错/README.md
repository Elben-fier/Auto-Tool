# 短剧审核 — 自动批量判错工具系列

目标页面：`https://tools.vobile.cn/quality/dramaReview*`（Vobile 短剧审核页）

## 功能概述

针对「短剧审核」页面逐条展开母行、批量判错的重复流程实现全自动化：

1. 展开母行，加载子样本表格（Ant Design Pro Table）
2. 按规则勾选应判错的子样本：
   - **全错筛选**（4.5 新增）：母行短剧名含关键词或字数过短 → 全部子样本判错
   - **阈值筛选**：父级匹配最高分 ≤ 95 → 全选；> 95 → 逐行勾选得分 < 90 的低分样本（Shift 连续多选加速）
3. 点击「批量错误」并自动确认弹窗
4. 点击「全剧审核」并自动确认弹窗
5. 自动进入下一行循环，直到整页处理完毕（首行状态为「已审核」即结束）

## 配置参数（以 4.5 为准）

| 参数 | 默认值 | 说明 |
|------|:---:|------|
| `parentScoreThreshold` | 95 | 父级匹配最高分阈值：≤ 该值走「全选」，> 该值走「低分筛选」 |
| `childScoreThreshold` | 90 | 子样本得分阈值：得分 < 该值判错 |
| `startRow` | 1 | 起始处理行号（从 1 开始） |
| `nameKeywords` | 25 个关键词 | 母行短剧名包含任一关键词 → 全选判错 |
| `nameMinLength` | 4 | 母行短剧名字数 ≤ 该值 → 全选判错 |
| `expandWaitMax` | 15000ms | 子表格加载最长等待 |
| `modalWaitMax` | 5000ms | 确认弹窗最长等待 |
| `afterActionDelay` | 2500ms | 点击确认后等待页面刷新 |
| `batchErrorExtraWait` | 2000ms | 批量错误后额外等待（避免全剧审核被跳过） |
| `checkInterval` | 500ms | 轮询检测间隔 |

## 页面结构依赖

```
母行   tr.ant-table-row.ant-table-row-level-0
  ├── 第3列 (td:nth-child(3)) 短剧名           ← 全错筛选依据
  ├── 第5列 (td:nth-child(5)) 匹配最高分       ← 父级阈值依据
  ├── 第7列 (td:nth-child(7)) 审核状态          ← "已审核" 结束判定
  └── 展开图标 (.ant-table-row-expand-icon)
展开行 tr.ant-table-expanded-row
  └── 子表格 (.ant-pro-table)
       ├── 表头全选 input.ant-checkbox-input
       ├── 子行 tr.ant-table-row，第8列得分，首列复选框
       └── 工具栏「批量错误」按钮
```

> 若页面改版导致选择器失效，优先调整各版本 `SELECTORS` 配置；弹窗定位问题请参照 4.1 的 `waitForConfirmBtn` 调试日志定位实际弹窗结构。

## 使用流程

1. Tampermonkey 安装 `短剧审核4.5.user.js`
2. 打开短剧审核页面，等待表格加载，右下角出现紫色「短剧审核助手 4.5」面板
3. 按需调整「处理行号」「父级阈值」「子级阈值」
4. 点击「开始运行」，脚本自动循环处理直至全部完成（弹窗提示处理条数）
5. 可随时「停止」；处理结果同步输出到浏览器控制台

## 注意事项

- 脚本会真实执行「批量错误」「全剧审核」并自动确认弹窗，属于**不可逆业务操作**，请先在少量数据上验证阈值与关键词配置。
- 父行状态为「已审核」时视为全部处理完成并自动停止。
- 同一页面勿与其他短剧审核脚本同时启用。
